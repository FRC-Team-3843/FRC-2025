# FRC-2025 Repository Source

> FRC Team 3843's 2025 REEFSCAPE season robot code — archived; season complete.

## Context

Two sub-projects: `2025Robot` (competition code, main branch; motor APIs updated to 2026 standards) and `2025Robot-SimplifiedMotion` (simplified drivetrain variant). No active development. `main` branch has current motor APIs (SparkMax + Phoenix6) but incomplete command-factory architecture. Deprecated branches (`2025_Archive`, `2025_Offseason_archive`) retain the original CANSparkMax API and should not be referenced for 2026+ work.

Primary reference value: swerve config (YAGSL), multi-mechanism sequencing, and lessons captured in [[frc-2025-lessons-reefscape]]. (source: .project-context.md, .standards.md)
