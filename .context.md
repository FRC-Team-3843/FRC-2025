## Competition control patterns (confirmed in code)

Operator Xbox controller: face buttons (A/B/X/Y) for algae intake sequences, bumpers for mechanism swap (SwapToLifter / SwapToClaw), POV/D-pad for lifter position presets (up=clear, down=stow, left=coral-score, right=coral-intake). Driver Xbox: bumpers for hang approach/execute, face buttons for intake/outtake rollers, Start = zeroGyro. Dual intake binding: A+B cover both lifter and claw intake paths. (source: 2025Robot/src/main/java/frc/robot/RobotContainer.java lines 154–221; from: frc-2025-lessons-reefscape-202606120638)

## Durable lessons (carry forward to FRC-2026)

See dedicated note `frc-2025-lessons-reefscape-202606120638` for full detail. Summary:
- **Alliance-control pitfall:** `allianceRelativeControl(true)` is present alongside `zeroGyro()` on Start button — double-compensation hazard if `zeroGyroWithAlliance()` is used instead. Use one or the other, never both. (source: RobotContainer.java lines 87, 246, 252; SwerveSubsystem.java lines 564–596)
- **POV for position presets:** D-pad is the cleanest ergonomic choice for discrete position presets (stow/intake/score/clear); confirmed working in competition.
- **Bumper-chord for mechanism swap:** left/right bumper as a mode-switch (lifter vs claw context) reduces total button count and is more intuitive than separate button banks.
